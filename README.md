# ⚡ Tap-Tap

Tap-Tap is a multiplayer Telegram Mini App game.

## Features

- 2–6 players
- Room codes
- Telegram Mini App
- Shareable rooms
- 10-second tap battle
- Real-time WebSocket multiplayer
- Player statistics
- Wins
- Losses
- Total score
- Best score
- Best taps
- Win streak
- Leaderboard
- Telegram bot
- PostgreSQL
- Railway deployment

## Run

```bash
npm install
npm start
